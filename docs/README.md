# PCDS Queue documentation

This folder contains the project documents for the PCDS Queue Management System.

| Folder | Contents |
| --- | --- |
| `01_Project_Overview` | Project background, scope, objectives, and architecture overview |
| `02_Requirements` | Functional and non-functional requirements |
| `03_Diagrams` | Use case, DFD, EER, and architecture diagrams |
| `04_Database` | Schema reference, data dictionary, and migration notes |
| `05_API` | Flask API endpoints, authentication, and request/response examples |
| `06_UI_Design` | Screenshots and UI specifications for Admin, Staff, Kiosk, TV Display, and Mobile |
| `07_Testing` | Test cases, test evidence, and results |
| `08_User_Manual` | Operating guides for administrators, staff, kiosk users, and students |
| `09_Deployment` | Installation, LAN configuration, release, and deployment instructions |

Start with [Project Overview](01_Project_Overview/README.md). The current LAN
and release instructions are in [`../DEPLOYMENT.md`](../DEPLOYMENT.md).
